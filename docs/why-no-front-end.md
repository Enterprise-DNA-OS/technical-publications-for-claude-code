# Why no front end

A technical publications team needs reusable content, current reviews, manual assembly and a reliable record of each release. Those records live in a database. A coding agent can read and change them through a small CLI. The manual, review pack and weekly dashboard are read-only HTML outputs.

A screen editor gives visual selection, inline comments, drag-and-drop ordering and direct layout control. This base uses XHTML files and plain-language instructions instead. It has no live collaboration, cloud hosting, mobile editor, print layout designer, translation service or authenticated reviewer portal. Complex Flare content requires conversion.

If your team needs a screen or a different stack, Enterprise DNA builds it into your version. The database and content remain yours.

The free code carries no seat fee. Hosting, your chosen coding agent and operations can have their own costs. Shared access and backups must be configured before using business documents.
